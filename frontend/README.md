# VoxMinds Frontend

React 18 + Vite 6 single-page application for the VoxMinds SIH 2026 prototype.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173

The FastAPI backend should run at http://127.0.0.1:8000.

> Do not run `npm create vite@latest` inside this directory. It is already a Vite project.
